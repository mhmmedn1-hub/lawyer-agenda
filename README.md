# أجندة المحامي

مشروع جديد مستقل عن المشروع الأصلي، تم تصميمه بشكل احترافي لإدارة المحامي، مع واجهة عربية كاملة، تسجيل دخول، إدارة الموكلين، القضايا، الجلسات، المهام، والتقارير.

## الحساب الافتراضي
- اسم المستخدم: محمد النزال
- كلمة المرور: 6503536

## التشغيل
```bash
npm install
npm start
```

ثم افتح:
```text
http://localhost:3000
```

## ملاحظات
- المشروع يتم حفظ بياناته محلياً داخل المتصفح باستخدام localStorage.
- هذا المشروع مستقل تماماً عن النسخة الأصلية ويُستخدم كنسخة احتياطية/تجريبية آمنة.
